# Botanical & Co.
### A Handmade Skincare Website

Botanical & Co. is a front-end website for a fictional handmade skincare brand. It showcases a collection of soaps, body-care products, lip-care products, and bath essentials through a clean, botanical-inspired design.

The project focuses on creating an attractive and user-friendly shopping experience while demonstrating the use of HTML, CSS, and JavaScript.

---

## Project Overview

The website presents Botanical & Co. as a skincare brand inspired by natural ingredients, simple routines, and thoughtfully designed products. Visitors can explore the product collection, learn about the brand, customise a gift box, and interact with the review section.

The design uses soft pastel colours, botanical elements, and responsive layouts to create a consistent visual identity.

## Features

- **Responsive Design:** Layout adapts to different screen sizes and devices.
- **Product Catalogue:** Displays 18 skincare and bath products with their names, descriptions, and sample prices.
- **Category Filters:** Allows visitors to browse products by category.
- **Image Slideshow:** Highlights selected products and brand visuals.
- **Dark Mode:** Provides an alternative viewing theme.
- **Brand Information:** Includes sections about the brand's mission, ingredients, and values.
- **Gift Box Builder:** Allows visitors to select exactly four soaps, choose a ribbon, and add an optional personal message.
- **Customer Reviews:** Displays sample testimonials and includes a form for adding reviews to the current page.
- **Deals and Coming Soon Sections:** Showcases sample offers and upcoming products.

## Getting Started

Follow these steps to run the project locally.

1. Download or clone the project repository.
2. Locate the `index.html` file.
3. Open `index.html` in a web browser.
4. Explore the website and try its interactive features.

An active internet connection is recommended because some images are loaded from external sources.

The website is currently contained in a single HTML file, including its CSS and JavaScript.

## Important Notes

- This project is a front-end demonstration and does not include a backend or database.
- Product prices and promotional offers are sample values.
- The displayed testimonials are fictional examples created for demonstration purposes.
- Reviews submitted through the form are stored only in the current page session and are not permanently saved.
- The gift box builder creates a preview of the selected items; it does not process orders or payments.
- No real purchases, payments, or customer accounts are supported.
