# Botanical & Co. 

A simple frontend website for a handmade soap and skincare boutique.

### Features
- Product catalog with skin concern filters.
- Ingredient information section.
- Essential oil scent profiles.
- Custom 4-bar gift box builder.
- Personalized ribbon selection.

### Built With
- HTML
- CSS
- JavaScript

### Getting Started
1. Clone the repository.
2. Open the project folder.
3. Run `index.html` in your browser.

### Status
Currently a basic frontend prototype. More features and improvements will be added as the project develops.
